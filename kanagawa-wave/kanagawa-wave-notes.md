# Kanagawa Wave — theme notes

- Source: https://github.com/rebelot/kanagawa.nvim
- Variant: Wave (default dark) · accent: crystalBlue
- Generated by `tools/build_theme.py` from `theme.spec.json`.

## Notes

- Variant: Wave, the plugin's default.
- Surfaces follow themes.lua's ui ramp: bg (sumiInk3) main, bg_dim/bg_m2 (sumiInk1) panels, bg_m3 (sumiInk0) rail, bg_p1/bg_p2 (sumiInk4/5) floating and nested.
- Accent: crystalBlue (syn.fun), the most characteristic Wave accent; pressed/TEXT_BRAND = springViolet2 (lighter blue-violet); BRAND_560 = waveBlue2 (bg_search).
- Links: springBlue (syn.special1), distinct from crystalBlue by ~20° of hue and underlined.
- Text: the palette has one foreground (ui.fg = fujiWhite), so strong and normal text are both fujiWhite; secondary = oldWhite (ui.fg_dim), muted = fujiGray (syn.comment), muted channels = sumiInk6 (ui.nontext).
- Status: diag.error samuraiRed, diag.ok springGreen, diag.warning roninYellow.
- Palette: lua/kanagawa/colors.lua; roles per variant from lua/kanagawa/themes.lua (palette_roles lists every themes.lua role a colour fills in this variant).

## Derived shades

- None: every colour is a palette colour.
