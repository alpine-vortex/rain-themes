# Dracula — theme notes

- Source: https://draculatheme.com/spec
- Variant: Dracula Classic (dark) · accent: purple
- Generated by `tools/build_theme.py` from `theme.spec.json`.

## Notes

- Variant: Dracula Classic (dark); Alucard is the light variant and is listed but unused.
- Surfaces follow the spec's UI palette: Background / Background Dark / Background Darker / Floating / Background Lighter.
- Hover, active and borders use Current Line as a translucent overlay, as the spec prescribes for line highlight and subtle borders.
- Accent: purple (most characteristic Dracula accent); brighter = ANSI bright blue #D6ACFF, darker (BRAND_560) = Functional Purple (focus colour).
- Substitution: the spec's Functional state colours (red #DE5735, green #089108, orange #A39514, cyan #0081D6 for links) are 3.4–3.7:1 on the dark background — they fail as text. Used the classic Red / Green / Orange and Cyan for links instead.
- Derived: text_secondary = 60% Foreground + 40% Comment (only one foreground in the palette). Strong text = ANSI bright white.
- Muted text keeps Comment (spec role) at ~3.0:1 — dim by design, not body text.
