# Rosé Pine — desktop exports

Generated by `tools/desktop_export.py`. Apply with `tools/apply_theme.py rose-pine`;
the steps below are the ones a script can't do.

## Dark Reader (ChatGPT and other sites)
On the site, open the Dark Reader popup → **Theme** → **Colors** (use its site-only option to keep other sites as they are):

| Setting | Value |
|---|---|
| Background | `#191724` |
| Text | `#E0DEF4` |
| Selection | `#C4A7E7` |

## Niagara Launcher (phone)
1. Set `wallpaper-phone.png` as the wallpaper.
2. Niagara → Theme colour → pick the **Wallpaper and System** swatch closest to `#C4A7E7`.
   Fallback in **Standard**: **magenta**.
3. Export the theme (`.nlt`) and commit it here as `rose-pine.nlt`.

## Sync for Reddit (phone)
Copy the JSON below (or `sync-theme.json`) and paste it into Sync's Monet theme
import; Sync only imports from the clipboard. It sets the seed `#C4A7E7` and the dark text colours; Sync derives
backgrounds and cards from the seed, so they are tinted near-black rather than
`#191724`.

```json
{
  "monet_override_light_secondary_text_color": 0,
  "monet_override_light_primary_text_color": 0,
  "monet_override_light_link_color": 0,
  "monet_boost_light_color": false,
  "monet_override_dark_secondary_text_color": "#908CAA",
  "monet_override_dark_primary_text_color": "#E0DEF4",
  "monet_override_dark_link_color": "#9CCFD8",
  "monet_boost_dark_color": true,
  "monet_color_intensity": 1,
  "monet_manual_theme_color": "#C4A7E7",
  "monet_system": false
}
```

## Termius (phone)
Settings → Terminal theme & font → Pick **Rosé Pine**; it's the same upstream palette. Claude Code over SSH then follows it
(`/theme` → *ANSI colours only*).

## HeliBoard (phone)
HeliBoard → Settings → Appearance → Colors → **Load**, then pick
`rose-pine.heliboard.json` and `rose-pine-light.heliboard.json` (Rosé Pine Dawn, for day mode). It can also be pasted from the clipboard.
Choose the theme for night (and day) in the same screen.

## Android apps (app-theme)
Apps that read the app-theme format (such as redeye) import
`rose-pine.app-theme.json` by file, clipboard, or this URL:
`https://raw.githubusercontent.com/alpine-vortex/rain-themes/main/rose-pine/desktop/rose-pine.app-theme.json`

## Firefox Color (other machines)
With `rain apply`, Firefox uses userChrome.css (exact colours). Elsewhere, install
the Firefox Color extension and open the `url` in `firefox-color.json`.
Firefox for Android doesn't support themes; use Dark Reader there (values above).

## Claude Code
Once: `/theme` → the *ANSI colours only* dark option. It then follows the terminal palette.
