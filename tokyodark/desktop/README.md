# Tokyo Dark — desktop exports

Generated by `tools/desktop_export.py`. Apply with `tools/apply_theme.py tokyodark`;
the steps below are the ones a script can't do.

## Dark Reader (ChatGPT and other sites)
On the site, open the Dark Reader popup → **Theme** → **Colors** (use its site-only option to keep other sites as they are):

| Setting | Value |
|---|---|
| Background | `#11121D` |
| Text | `#A0A8CD` |
| Selection | `#7199EE` |

## Niagara Launcher (phone)
1. Set `wallpaper-phone.png` as the wallpaper.
2. Niagara → Theme colour → pick the **Wallpaper and System** swatch closest to `#7199EE`.
   Fallback in **Standard**: **indigo**.
3. Export the theme (`.nlt`) and commit it here as `tokyodark.nlt`.

## Sync for Reddit (phone)
Import `sync-theme.json` in Sync's Monet theme settings, where its theme export
comes from. It sets the seed `#7199EE` and the dark text colours; Sync derives
backgrounds and cards from the seed, so they are tinted near-black rather than
`#11121D`.

```json
{
  "monet_override_light_secondary_text_color": 0,
  "monet_override_light_primary_text_color": 0,
  "monet_override_light_link_color": 0,
  "monet_boost_light_color": false,
  "monet_override_dark_secondary_text_color": "#8A92B0",
  "monet_override_dark_primary_text_color": "#A0A8CD",
  "monet_override_dark_link_color": "#A485DD",
  "monet_boost_dark_color": true,
  "monet_color_intensity": 1,
  "monet_manual_theme_color": "#7199EE",
  "monet_system": false
}
```

## Termius (phone)
Settings → Terminal theme & font → Pick **Tokyo Night**, the closest built-in; Termius has no Tokyo Dark theme, so colours differ somewhat from the terminal palette below. Claude Code over SSH then follows it
(`/theme` → *ANSI colours only*).

## redeye (phone)
Import `redeye-theme.json` (file, clipboard, or this URL):
`https://raw.githubusercontent.com/alpine-vortex/rain-themes/main/tokyodark/desktop/redeye-theme.json`

## Firefox Color (other machines)
On spacer, `apply_theme.py` uses userChrome.css (exact colours). Elsewhere, install
the Firefox Color extension and open the `url` in `firefox-color.json`.
Firefox for Android doesn't support themes; use Dark Reader there (values above).

## Claude Code
Once: `/theme` → the *ANSI colours only* dark option. It then follows the terminal palette.
