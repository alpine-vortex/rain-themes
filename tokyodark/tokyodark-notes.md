# Tokyo Dark — theme notes

- Source: https://github.com/tiagovla/tokyodark.nvim
- Variant: Default (gamma 1.0) · accent: blue
- Generated by `tools/build_theme.py` from `theme.spec.json`.

## Notes

- Variant: the plugin has one palette; default gamma 1.0 used.
- Accent: blue (FloatTitle, MoreMsg, link URLs). Red is taken by TabLineSel but collides with danger; green (lualine/PmenuSel) collides with online. Links use purple, the documented link-label colour, to stay distinct from the blue accent.
- Strong text uses bg_blue: the palette has a single foreground (fg), and bg_blue is its only lighter cool tone.
- Derived: text_secondary / text_muted / interactive_muted are mixes of fg and bg4. bg4 (Comment) is ~2.3:1 on bg0, too dim for text.
- Tertiary uses the palette's 'black' (#06080A), darker than bg0.
- Author 'emeet' taken from git config.
