# Tokyo Night Night — theme notes

- Source: https://github.com/folke/tokyonight.nvim
- Variant: Night style · accent: blue
- Generated by `tools/build_theme.py` from `theme.spec.json`.

## Notes

- Variant: night style. Hexes taken from the repo's generated extras/lua/tokyonight_night.lua (fully resolved palette).
- Accent: blue (Title, Directory, TabLineSel). Links: teal, the colour of @markup.link. Brighter accent = terminal bright blue; darker (BRAND_560) = blue0.
- Secondary background = bg_dark, the plugin's sidebar/statusline/float colour; tertiary = bg_dark1. Floating surfaces use bg_highlight (CursorLine) rather than bg_dark so sheets stand out from the chat.
- Text: the palette has one bright foreground, so strong and normal text are both fg; secondary uses fg_dark (the sidebar foreground).
- Substitution: muted text uses dark5 instead of comment (comment is below 3:1 on bg); comment kept for INTERACTIVE_MUTED.
- Button/badge text is 'black', matching TabLineSel (black on blue).

## Derived shades

- None: every colour is a palette colour.
