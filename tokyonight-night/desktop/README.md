# Tokyo Night Night — desktop exports

Generated by `tools/desktop_export.py`. Apply with `tools/apply_theme.py tokyonight-night`;
the steps below are the ones a script can't do.

## Dark Reader (ChatGPT and other sites)
On the site, open the Dark Reader popup → **Theme** → **Colors** (use its site-only option to keep other sites as they are):

| Setting | Value |
|---|---|
| Background | `#1A1B26` |
| Text | `#C0CAF5` |
| Selection | `#7AA2F7` |

## Niagara Launcher (phone)
1. Set `wallpaper-phone.png` as the wallpaper.
2. Niagara → Theme colour → pick the **Wallpaper and System** swatch closest to `#7AA2F7`.
   Fallback in **Standard**: **indigo**.
3. Export the theme (`.nlt`) and commit it here as `tokyonight-night.nlt`.

## Sync for Reddit (phone)
Copy the JSON below (or `sync-theme.json`) and paste it into Sync's Monet theme
import; Sync only imports from the clipboard. It sets the seed `#7AA2F7` and the dark text colours; Sync derives
backgrounds and cards from the seed, so they are tinted near-black rather than
`#1A1B26`.

```json
{
  "monet_override_light_secondary_text_color": 0,
  "monet_override_light_primary_text_color": 0,
  "monet_override_light_link_color": 0,
  "monet_boost_light_color": false,
  "monet_override_dark_secondary_text_color": "#A9B1D6",
  "monet_override_dark_primary_text_color": "#C0CAF5",
  "monet_override_dark_link_color": "#1ABC9C",
  "monet_boost_dark_color": true,
  "monet_color_intensity": 1,
  "monet_manual_theme_color": "#7AA2F7",
  "monet_system": false
}
```

## Termius (phone)
Settings → Terminal theme & font → Pick **Tokyo Night**; it's the same upstream palette. Claude Code over SSH then follows it
(`/theme` → *ANSI colours only*).

## HeliBoard (phone)
HeliBoard → Settings → Appearance → Colors → **Load**, then pick
`tokyonight-night.heliboard.json` and `tokyonight-night-light.heliboard.json` (Tokyo Night Day, for day mode). It can also be pasted from the clipboard.
These are "all colors" themes (every keyboard element set exactly); the
`.heliboard-simple.json` files are the 10-colour version. Choose the theme for
night (and day) in the same screen.

## Android apps (app-theme)
Apps that read the app-theme format (such as redeye) import
`tokyonight-night.app-theme.json` by file, clipboard, or this URL:
`https://raw.githubusercontent.com/alpine-vortex/rain-themes/main/tokyonight-night/desktop/tokyonight-night.app-theme.json`

## Firefox Color (other machines)
With `rain apply`, Firefox uses userChrome.css (exact colours). Elsewhere, install
the Firefox Color extension and open the `url` in `firefox-color.json`.
Firefox for Android doesn't support themes; use Dark Reader there (values above).

## Claude Code
`rain apply` (target `claude`) writes `tokyonight-night.claude-theme.json` to
`~/.claude/themes/rain.json` and sets `"theme": "custom:rain"` in
`~/.claude/settings.json`; running sessions switch live. Elsewhere, copy the file there
and pick **Rain Tokyo Night Night** with `/theme`. It colours the terminal app only (with the Rain terminal profile behind it):
the Claude app and claude.ai/code don't take custom themes. What does reach them is
`/color blue` (the closest of its eight colours to the accent), which
syncs to claude.ai/code for a Remote Control session.

## tmux
`rain apply` (target `tmux`) writes `tokyonight-night.tmux.conf` to `~/.config/tmux/rain.conf` and
reloads every running tmux server, so open sessions change too. Add once to your tmux.conf:
`source-file -q ~/.config/tmux/rain.conf`. Elsewhere (another host), copy the file there.
Only styles are set; formats stay yours, and `#{@rain_accent}` and friends are there to use.

## Forgejo
Copy `theme-rain-tokyonight-night.css` (dark), `theme-rain-tokyonight-night-auto.css` (follows the browser; Tokyo Night Day when light) and `theme-rain-tokyonight-night-light.css` into the server's
`$FORGEJO_CUSTOM/public/assets/css/`, or let `tools/rain forgejo` gather every palette's
files and print the `[ui] THEMES` line for `app.ini`.
