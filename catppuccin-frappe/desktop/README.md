# Catppuccin Frappé — desktop exports

Generated by `tools/desktop_export.py`. Apply with `tools/apply_theme.py catppuccin-frappe`;
the steps below are the ones a script can't do.

## Dark Reader (ChatGPT and other sites)
On the site, open the Dark Reader popup → **Theme** → **Colors** (use its site-only option to keep other sites as they are):

| Setting | Value |
|---|---|
| Background | `#303446` |
| Text | `#C6D0F5` |
| Selection | `#CA9EE6` |

## Niagara Launcher (phone)
1. Set `wallpaper-phone.png` as the wallpaper.
2. Niagara → Theme colour → pick the **Wallpaper and System** swatch closest to `#CA9EE6`.
   Fallback in **Standard**: **magenta**.
3. Export the theme (`.nlt`) and commit it here as `catppuccin-frappe.nlt`.

## Sync for Reddit (phone)
Copy the JSON below (or `sync-theme.json`) and paste it into Sync's Monet theme
import; Sync only imports from the clipboard. It sets the seed `#CA9EE6` and the dark text colours; Sync derives
backgrounds and cards from the seed, so they are tinted near-black rather than
`#303446`.

```json
{
  "monet_override_light_secondary_text_color": 0,
  "monet_override_light_primary_text_color": 0,
  "monet_override_light_link_color": 0,
  "monet_boost_light_color": false,
  "monet_override_dark_secondary_text_color": "#B5BFE2",
  "monet_override_dark_primary_text_color": "#C6D0F5",
  "monet_override_dark_link_color": "#8CAAEE",
  "monet_boost_dark_color": true,
  "monet_color_intensity": 1,
  "monet_manual_theme_color": "#CA9EE6",
  "monet_system": false
}
```

## Termius (phone)
Settings → Terminal theme & font → Pick **Catppuccin Mocha**, the closest built-in; Termius has no Catppuccin Frappé theme, so colours differ somewhat from the terminal palette below. Claude Code over SSH then follows it
(`/theme` → *ANSI colours only*).

## redeye (phone)
Import `redeye-theme.json` (file, clipboard, or this URL):
`https://raw.githubusercontent.com/alpine-vortex/rain-themes/main/catppuccin-frappe/desktop/redeye-theme.json`

## Firefox Color (other machines)
On spacer, `apply_theme.py` uses userChrome.css (exact colours). Elsewhere, install
the Firefox Color extension and open the `url` in `firefox-color.json`.
Firefox for Android doesn't support themes; use Dark Reader there (values above).

## Claude Code
Once: `/theme` → the *ANSI colours only* dark option. It then follows the terminal palette.
