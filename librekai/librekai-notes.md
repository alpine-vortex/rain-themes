# Librekai — theme notes

- Source: https://github.com/microsoft/vscode/tree/main/extensions/theme-monokai
- Variant: Classic Monokai · accent: pink
- Generated by `tools/build_theme.py` from `theme.spec.json`.

## Notes

- Source: VS Code's built-in Monokai theme (microsoft/vscode extensions/theme-monokai, MIT; upstream Colorsublime/Colorsublime-Themes, MIT). Monokai was originally designed by Wimer Hazenberg (2006). No Monokai Pro material is used.
- Palette colours are named after the first VS Code key or token that uses them; palette_roles lists the rest.
- Surfaces follow the VS Code roles: chat = editor.background, panels/rail = sideBar/titleBar, sheets and inputs = list.hoverBackground/lineHighlight, nested = indent guide.
- Accent: Monokai pink. Pure #F92672 gives 4.45:1 with the darkest palette colour as button text (just under 4.5), so the brand is pink lightened 10% toward the foreground (derived); pure #F92672 is kept as BRAND_560 and in the mention/selected tints.
- Danger uses #F44747 (the theme's error-token colour) so it isn't the accent pink; warning uses orange so idle doesn't blend with lime online.
- Only one foreground colour: strong and normal text are both #F8F8F2; secondary uses tab.inactiveForeground, muted uses the line-number colour, muted channels the comment colour.

Host `librekai.json` at a raw URL (e.g. raw.githubusercontent.com), then add it by URL in Rain → Themes.
