# Librekai Refined — desktop exports

Generated by `tools/desktop_export.py`. Apply with `tools/apply_theme.py librekai-refined`;
the steps below are the ones a script can't do.

## Dark Reader (ChatGPT and other sites)
On the site, open the Dark Reader popup → **Theme** → **Colors** (use its site-only option to keep other sites as they are):

| Setting | Value |
|---|---|
| Background | `#272822` |
| Text | `#E8E8E3` |
| Selection | `#66D9EF` |

## Niagara Launcher (phone)
1. Set `wallpaper-phone.png` as the wallpaper.
2. Niagara → Theme colour → pick the **Wallpaper and System** swatch closest to `#66D9EF`.
   Fallback in **Standard**: **blue**.
3. Export the theme (`.nlt`) and commit it here as `librekai-refined.nlt`.

## Sync for Reddit (phone)
Copy the JSON below (or `sync-theme.json`) and paste it into Sync's Monet theme
import; Sync only imports from the clipboard. It sets the seed `#66D9EF` and the dark text colours; Sync derives
backgrounds and cards from the seed, so they are tinted near-black rather than
`#272822`.

```json
{
  "monet_override_light_secondary_text_color": 0,
  "monet_override_light_primary_text_color": 0,
  "monet_override_light_link_color": 0,
  "monet_boost_light_color": false,
  "monet_override_dark_secondary_text_color": "#D8D8D3",
  "monet_override_dark_primary_text_color": "#E8E8E3",
  "monet_override_dark_link_color": "#A6E22D",
  "monet_boost_dark_color": true,
  "monet_color_intensity": 1,
  "monet_manual_theme_color": "#66D9EF",
  "monet_system": false
}
```

## Termius (phone)
Settings → Terminal theme & font → Pick **Monokai**, the closest built-in; Termius has no Librekai Refined theme, so colours differ somewhat from the terminal palette below. Claude Code over SSH then follows it
(`/theme` → *ANSI colours only*).

## Android apps (app-theme)
Apps that read the app-theme format (such as redeye) import
`librekai-refined.app-theme.json` by file, clipboard, or this URL:
`https://raw.githubusercontent.com/alpine-vortex/rain-themes/main/librekai-refined/desktop/librekai-refined.app-theme.json`

## Firefox Color (other machines)
With `rain apply`, Firefox uses userChrome.css (exact colours). Elsewhere, install
the Firefox Color extension and open the `url` in `firefox-color.json`.
Firefox for Android doesn't support themes; use Dark Reader there (values above).

## Claude Code
Once: `/theme` → the *ANSI colours only* dark option. It then follows the terminal palette.
