# Librekai Refined — theme notes

- Source: https://github.com/crusoexia/vim-monokai
- Variant: Refined Monokai · accent: aqua
- Generated by `tools/build_theme.py` from `theme.spec.json`.

## Notes

- Source: crusoexia/vim-monokai (MIT). No Monokai Pro material is used.
- Accent: aqua, the scheme's selection colour (PmenuSel) and Directory colour; brighter shade = its pale cyan.
- Links: green, the scheme's Underlined colour. Online/positive uses br_green so it isn't identical to links.
- Danger: the scheme's true red #E73C50 (ErrorMsg), distinct from the keyword pink.
- Chat is Normal bg (black), panels/rail darkblack (Pmenu/VertSplit bg), sheets CursorLine, nested the Error bg grey, inputs the LineNr/SignColumn bg.
- Derived: BRAND_560 is 70% aqua + 30% black (the palette has no darker aqua).
