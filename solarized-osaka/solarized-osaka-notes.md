# Solarized Osaka — theme notes

- Source: https://github.com/craftzdog/solarized-osaka.nvim
- Variant: Default dark style · accent: Solarized blue
- Generated by `tools/build_theme.py` from `theme.spec.json`.

## Notes

- Variant: none specified, so the plugin's default dark style (not vivid/light).
- Palette is defined in HSL in lua/solarized-osaka/colors.lua; converted with the plugin's own hslToHex (LuaJIT truncation). Hexes match the repo's Discord extra (#001419, #268BD3, #29A298).
- Accent: blue, as in the repo's own Discord extra (brand = blue). That extra also uses blue for links, so links use cyan500 (hint) to stay distinct.
- Tertiary = main (base04): nothing darker exists in the palette. PRIMARY_700 and PRIMARY_800 both base04 for the same reason.
- Floating surfaces use base03 rather than the plugin's 'dark' floats (base04) so sheets are visible over the base04 chat.
- Substitution: danger red500 (error) was 4.01:1 on main / 3.16:1 on secondary; switched to red300.
- Substitution: muted text base01 (Comment) was 2.71:1 on inputs; switched to base00. base01 kept for INTERACTIVE_MUTED.
- Button/badge text is base04: light text is ~2.97:1 on blue.

## Derived shades

- None: every colour is a palette colour.
