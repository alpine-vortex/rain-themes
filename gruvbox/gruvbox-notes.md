# Gruvbox — theme notes

- Source: https://github.com/morhetz/gruvbox
- Variant: Dark · medium contrast (default) · accent: bright orange
- Generated by `tools/build_theme.py` from `theme.spec.json`.

## Notes

- Variant: none specified, so the default dark / medium contrast (g:gruvbox_contrast_dark='medium', gruvbox.vim:73).
- Accent: none specified; bright_orange chosen as the scheme's most characteristic accent. Warning/idle uses yellow so it doesn't collide with the orange brand.
- Roles followed from gruvbox.vim: Normal = fg1 on bg0, Comment = gray, Underlined = blue (links), Pmenu = bg2.
- Secondary background (dark0_soft) is slightly lighter than main (dark0) so every layer stays a palette colour.
- Button/badge text is dark0: light text fails on orange.
- Danger text (bright_red) is ~4.3:1 on main — no lighter red in the palette; status text, not body text.
- Red and orange are separated by hue only (luminance ratio ~1.36).
