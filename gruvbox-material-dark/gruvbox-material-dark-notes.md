# Gruvbox Material Dark — theme notes

- Source: https://github.com/sainnhe/gruvbox-material
- Variant: Dark · background medium · foreground material · accent: blue
- Generated by `tools/build_theme.py` from `theme.spec.json`.

## Notes

- Config used: g:gruvbox_material_background='medium', g:gruvbox_material_foreground='material' (both plugin defaults), dark background; palette from get_palette() in autoload/gruvbox_material.vim.
- Roles from colors/gruvbox-material.vim: Normal = fg0 on bg0, Pmenu = fg1 on bg3, Comment = grey1, LineNr = grey0, StatusLine = grey2 on bg_statusline2, PmenuSel/TabLineSel use grey2 (default 'grey' menu selection).
- Distinct from the Gruvbox theme: selection follows gruvbox-material's grey-first UI (grey2 @ 25%) instead of an accent tint; accent is the teal-leaning blue (Todo/DiagnosticInfo) rather than orange; mentions use the yellow tint (the palette's bg_visual_yellow family).
- Links: the scheme doesn't colour links (Underlined/htmlLink are underline-only), so links use purple to stay clear of the blue accent.
- Derived: brand_bright = 65% blue + 35% fg1 (no brighter teal in the palette), used for pressed buttons and TEXT_BRAND.
- Substitution: nested floating surfaces were bg5 (#5A524C), but fg0 on it is 4.23:1; switched to bg_statusline3 (#504945).
- BRAND_560 = bg_diff_blue (the palette's only dark teal).
- Strong text is fg1: the palette's lightest foreground; only slightly brighter than fg0 by design.
- Author 'emeet' taken from git config.

## Install

Host `gruvbox-material-dark.json` at a raw URL (e.g. raw.githubusercontent.com), then add it by URL in Rain → Themes.
