# Gruvbox Material Dark — desktop exports

Generated by `tools/desktop_export.py`. Apply with `tools/apply_theme.py gruvbox-material-dark`;
the steps below are the ones a script can't do.

## Dark Reader (ChatGPT and other sites)
On the site, open the Dark Reader popup → **Theme** → **Colors** (use its site-only option to keep other sites as they are):

| Setting | Value |
|---|---|
| Background | `#282828` |
| Text | `#D4BE98` |
| Selection | `#7DAEA3` |

## Niagara Launcher (phone)
1. Set `wallpaper-phone.png` as the wallpaper.
2. Niagara → Theme colour → pick the **Wallpaper and System** swatch closest to `#7DAEA3`.
   Fallback in **Standard**: **teal**.
3. Export the theme (`.nlt`) and commit it here as `gruvbox-material-dark.nlt`.

## Sync for Reddit (phone)
Copy the JSON below (or `sync-theme.json`) and paste it into Sync's Monet theme
import; Sync only imports from the clipboard. It sets the seed `#7DAEA3` and the dark text colours; Sync derives
backgrounds and cards from the seed, so they are tinted near-black rather than
`#282828`.

```json
{
  "monet_override_light_secondary_text_color": 0,
  "monet_override_light_primary_text_color": 0,
  "monet_override_light_link_color": 0,
  "monet_boost_light_color": false,
  "monet_override_dark_secondary_text_color": "#A89984",
  "monet_override_dark_primary_text_color": "#D4BE98",
  "monet_override_dark_link_color": "#D3869B",
  "monet_boost_dark_color": true,
  "monet_color_intensity": 1,
  "monet_manual_theme_color": "#7DAEA3",
  "monet_system": false
}
```

## Termius (phone)
Settings → Terminal theme & font → Pick **Gruvbox Dark**, the closest built-in; Termius has no Gruvbox Material Dark theme, so colours differ somewhat from the terminal palette below. Claude Code over SSH then follows it
(`/theme` → *ANSI colours only*).

## HeliBoard (phone)
HeliBoard → Settings → Appearance → Colors → **Load**, then pick
`gruvbox-material-dark.heliboard.json` and `gruvbox-material-dark-light.heliboard.json` (Gruvbox Material Light, for day mode). It can also be pasted from the clipboard.
These are "all colors" themes (every keyboard element set exactly); the
`.heliboard-simple.json` files are the 10-colour version. Choose the theme for
night (and day) in the same screen.

## Android apps (app-theme)
Apps that read the app-theme format (such as redeye) import
`gruvbox-material-dark.app-theme.json` by file, clipboard, or this URL:
`https://raw.githubusercontent.com/alpine-vortex/rain-themes/main/gruvbox-material-dark/desktop/gruvbox-material-dark.app-theme.json`

## Firefox Color (other machines)
With `rain apply`, Firefox uses userChrome.css (exact colours). Elsewhere, install
the Firefox Color extension and open the `url` in `firefox-color.json`.
Firefox for Android doesn't support themes; use Dark Reader there (values above).

## Claude Code
`rain apply` (target `claude`) writes `gruvbox-material-dark.claude-theme.json` to
`~/.claude/themes/rain.json`, which Claude Code reloads live. Once: `/theme` →
**Rain Gruvbox Material Dark**; later applies just swap the file. Elsewhere, copy the file there
yourself. It colours the terminal app only (with the Rain terminal profile behind it):
the Claude app and claude.ai/code don't take custom themes. What does reach them is
`/color cyan` (the closest of its eight colours to the accent), which
syncs to claude.ai/code for a Remote Control session.

## tmux
`rain apply` (target `tmux`) writes `gruvbox-material-dark.tmux.conf` to `~/.config/tmux/rain.conf` and
reloads running servers. Add once to your tmux.conf:
`source-file -q ~/.config/tmux/rain.conf`. Elsewhere (another host), copy the file there.
Only styles are set; formats stay yours, and `#{@rain_accent}` and friends are there to use.

## Forgejo
Copy `theme-rain-gruvbox-material-dark.css` (dark), `theme-rain-gruvbox-material-dark-auto.css` (follows the browser; Gruvbox Material Light when light) and `theme-rain-gruvbox-material-dark-light.css` into the server's
`$FORGEJO_CUSTOM/public/assets/css/`, or let `tools/rain forgejo` gather every palette's
files and print the `[ui] THEMES` line for `app.ini`.
