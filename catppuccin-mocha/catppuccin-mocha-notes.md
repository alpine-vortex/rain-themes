# Catppuccin Mocha — theme notes

- Source: https://github.com/catppuccin/catppuccin

## Notes

- Flavor: Mocha (dark), from catppuccin/palette palette.json v1.8.0.
- Roles follow the Catppuccin style guide: Base = background pane, Mantle/Crust = secondary panes, Surface 0–2 = surface elements, Text = body copy & headlines, Subtext = labels, Overlay 1 = subtle text, Base = text on accent, Blue = links, Green/Yellow/Red = success/warnings/errors.
- Hover = Text at 10% (the guide's cursor-line value); active = Overlay 2 at 25% (the guide's selection range).
- Accent: mauve (default; the guide doesn't mandate one).
- Strong and normal text are both Text — the guide uses Text for both body copy and headlines. Channels use Subtext 1, so unread (Text) still stands out.
- Derived: brand_bright = 70% mauve + 30% text; BRAND_560 = 70% mauve + 30% crust (the palette has one mauve).
