## Notes

- Variant: Rosé Pine Moon. Palette from rose-pine/rose-pine-palette palette.json; highlight low/med/high (not in palette.json) from rosepinetheme.com/palette.
- Roles follow the per-colour usage docs in rose-pine/rose-pine-site: base = primary background, surface = inputs/status bars, overlay = dialogs, highlight_med = hovered popup items, subtle = secondary text, muted = disabled/dimmed labels, love = errors, gold = warnings, pine = affirmative signals, foam = informational.
- Secondary (channel list) uses surface rather than base (the docs put sidebars on base) so the channel list separates from chat. Tertiary = base: nothing darker in the palette.
- Accent: iris. Rose is the namesake, but love (danger) and rose are only ~19° apart in hue — closer still in Moon — so iris keeps danger clearly distinct. Links use foam (informational).
- Strong and normal text are both 'text': the palette has a single high-contrast foreground.
- Positive/online uses pine, the documented affirmative colour (Rosé Pine has no green).
- Placeholder text uses muted (the build groups placeholders with muted text); the docs suggest subtle for placeholders.
- Derived: brand_bright = 60% iris + 40% text; BRAND_560 = 70% iris + 30% base.
- Substitution: subtle is 4.46:1 on Moon's surface (channel list), just under 4.5; secondary text is subtle nudged 10% toward text (derived).
- Author 'emeet' taken from git config.
