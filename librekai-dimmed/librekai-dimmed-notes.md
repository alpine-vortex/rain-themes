# Librekai Dimmed — theme notes

- Source: https://github.com/microsoft/vscode/tree/main/extensions/theme-monokai-dimmed
- Variant: Monokai Dimmed · accent: amber
- Generated by `tools/build_theme.py` from `theme.spec.json`.

## Notes

- Source: VS Code's built-in Monokai Dimmed theme (microsoft/vscode extensions/theme-monokai-dimmed, MIT). No Monokai Pro material is used.
- Accent: amber #E58520 — the theme's own UI highlight (list.highlightForeground; cursor is the darker #C07020, used as BRAND_560). The theme's blue focus colour #3655B5 was rejected: no text colour passes on it and also reads as TEXT_BRAND on the dark chat.
- Links use #6796E6 (info-token blue); the syntax blue #6089B4 is 4.4:1 on the chat, just under 4.5.
- Danger uses #F44747 (error-token red); the syntax red #C7444A is under 3:1 on the chat.
- The theme's sidebar and activity bar are lighter than the editor; the rail uses the editor background (darkest) instead so layers read in Discord's order.
- Warning yellow is ~16° from the amber accent in hue but much lighter.
- Author 'emeet' taken from git config.
